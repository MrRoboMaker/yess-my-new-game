# My First Godot Game

## About the Game

This is my first game development project, created using the Godot Engine. It is a 2D obstacle-platformer where players navigate through different platforms and obstacles while trying to reach the end of the level.

The project is an opportunity for me to learn the fundamentals of game development, including player movement, collisions, level design, and working with 2D assets.

## How to Run Locally

1. Download or clone this repository.
2. Install the [Godot Engine](https://godotengine.org/).
3. Open Godot and select **Import**.
4. Select the downloaded project folder containing `project.godot`.
5. Open the project and press **F6** or **F5** to run the game.

## Built With

- Godot Engine 4
- GDScript
- 2D pixel-art assets
